\# Password Strength Checker



\## Project Overview

The Password Strength Checker is a beginner-friendly Python project developed for the DecodeLabs internship. It evaluates a password using basic security criteria and classifies it as Weak, Medium, or Strong.



\## Features

\- Checks minimum password length.

\- Checks for uppercase and lowercase letters.

\- Checks for numbers and special symbols.

\- Displays a strength rating.

\- Provides feedback for each security check.



\## Technologies Used

\- Python 3

\- `string` module



\## How to Run

1\. Install Python 3.

2\. Download or clone this repository.

3\. Open PowerShell or a terminal in the project folder.

4\. Run:



&#x20;  `py password\_checker.py`



5\. Enter a fictional test password when prompted.



If interactive input is unavailable in your terminal, you can test the program by piping a fictional password into it:



`"StrongTest123!" | py password\_checker.py`



\## Testing

The program was tested with fictional passwords representing weak, medium, and strong examples.



\## Security Note

This project is for educational purposes. It uses basic password-strength rules and does not guarantee that a password is secure. Never use real account passwords for demonstrations or testing.
